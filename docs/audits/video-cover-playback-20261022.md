# P05 — общая логика видеообложек

Запрос Алексея от 22.10.2026: hover на desktop, центр и очередь на touch, остановка при выходе любого края, уменьшение мобильных карточек стран на 10–15%, переиспользование чужих hero по форме области на всём сайте. Названия стран на примерах не являются условиями кода.

## Что опубликовано

Общие контроллер `src/scripts/video-covers.mjs` и политика `src/lib/cover-playback-policy.mjs` работают для всех обложек. На desktop нужен курсор внутри полностью видимой области; уход скрывает видео и возвращает его первый кадр. Отсутствие fine-hover у компьютера без touch input не включает autoplay.

На телефонах и планшетах дополнительная обложка ждёт пересечения своей вертикальной середины с серединой visual viewport. Ряд определяется координатами top/height с допуском 2 CSS px. Видео идут по фактическому left, слева направо; ended передаёт ход следующему, после последнего цикл повторяется. Ряд сохраняет ход после прохождения центра до нового ряда. Полная видимость важнее очереди: выход любого края останавливает показ. Собственный первый hero на touch играет, пока целиком видим. Скрытая вкладка останавливает видео.

Для заимствованного hero ширина>=высоты выбирает горизонтальный src, высота>ширины — mobileSrc, независимо от устройства. Отсутствующий формат оставляет исходное фото. Собственный hero сохраняет device-выбор источника. Автоматический каталог сопоставляет точный hero.src с видео и canonical owner активной страницы; не сопоставляет названия стран. Подключены Hero, обе разновидности DestinationBand, InterestCard, StoryPair, карточки мест/экскурсий, галереи, главные впечатления, дни тура/встроенные экскурсии и фотокарточки главной. Общая schema и шаблоны Country/Destination/Tour/Excursion/Theme/Case поддерживают src/mobileSrc.

Кадр выбирается по точному ролику из существующего реестра. Редакционное фото в видео-ветке остаётся инертным. Дополнительные кадры/фото ждут общего окна lazy load; MP4 получает src только при условии play. Новых медиа и перекодирования нет.

Страны главной до 760px: clamp(360px,105vw,460px) → clamp(315px,91.875vw,402.5px), −12,5%. Общий выбор формата позволяет существующий горизонтальный ролик в ставшей горизонтальной мобильной карточке; отдельного условия для Бразилии нет.
