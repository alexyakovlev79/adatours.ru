# Географическое SEO «русский гид»

Версия 1.0 · 27.10.2026. Только русский язык и действующие канонические страницы.

## Единственный редактируемый список

Файл: `src/data/seo/russian-guide-targets.json`.

- `enabled`: включение и выключение правила.
- `titleSuffix`: `, русский гид` непосредственно перед ` | Ada Tours`.
- `brandSuffix`: текст единого окончания title.
- `descriptionPrefix`: отдельная фраза с «Русский гид» в начале meta description.
- `countryIds`: 11 выбранных стран целиком.
- `destinationGroups`: 20 групп с географическими названиями и точными stable Destination ID. Патагония и Атакама включают места нескольких районов; Игуасу включает обе стороны границы.

Все идентификаторы выбираются из `src/data/catalog/destinations.json` либо каталога стран. Добавляй или удаляй ID в конфигурации без редактирования MD страниц.

## Область действия

Страна в `countryIds` охватывает весь ее раздел и каталоги. Для остальных стран охватываются только явно перечисленные Destination, туры/экскурсии с такой связью и каталоги выбранного места. При добавлении новых туров/экскурсий с теми же IDs метатеги появляются автоматически.

Дополнительно охвачены тематические каталоги страны, VIP-каталоги страны и явно заданные multi-country сочетания с выбранной страной. Общие индексы `/tours/`, `/places/`, `/excursions/`, `/multi-country/`, прочие общие страницы и неспецифические категории не меняются.

Для тура используются `countries`, `routeCountries`, `destinations`, `routeDestinations`; для экскурсии — `country`, `destination`, `relatedDestinations`. Текстовый поиск по названиям запрещен: Морро-де-Сан-Паулу не становится городом Сан-Паулу, а две стороны Игуасу остаются разными stable ID.

Архивные и черновые сущности, не-RU страницы и redirect aliases исключены. Повторное выполнение идемпотентно.

## Где правило применяется технически

`src/lib/russian-guide-seo.mjs` вызывается из `src/lib/page-schema.ts` **после** расчета цен в SEO-title и description. Оно синхронизирует title/meta description с OG/Twitter и `WebPage` JSON-LD. H1, canonical, цены, тела SEO/GEO-статей, тексты, маршруты, фотографии и связи не редактируются.

Пример: `Тур по Рио, русский гид | Ada Tours`. Для старых SEO-title с конечным `Ada Tours` без `|` подпись нормализуется в одно конечное ` | Ada Tours`.

Запуск проверки: `node --test tests/russian-guide-seo.test.mjs`. Тест входит в штатный `npm run build`. Для применения нового списка нужна очередная статическая сборка/deploy.
