# Взаимные sameAs на adatours.ru (срез 22.10.2026)

Единственный источник внедрения — локальный проверенный JSON
`data/external-identity/site-sameas-20261022.json`. Это одноразовый статический снимок утвержденного реестра соответствий, а не внешний сервис.

- vipdeluxetravel.ru: 1271 точный исходный URL, временно разрешен (до окончательной индексации и склейки).
- adatours.com: 351 URL.
- brasiltours.ru: 674 URL по архивному сохраненному срезу, без повторного парсинга.
- 948 уникальных RU target path (содержат также производные каталоги и служебные страницы).

Сайт никогда не запрашивает Google Sheets ни при build, ни при открытии страницы. Импорт JSON в Astro серверный, данные не превращаются в отдельный клиентский bundle. `src/lib/external-page-sameas.mjs` индексирует пары в памяти один раз на процесс сборки и добавляет исключительно список URL в существующий JSON-LD, на главную сущность конкретной страницы или WebPage для производного каталога. Сам HTML не содержит новой загрузки сетевых ресурсов и не зависит от GitHub/Drive при открытии.

Прежняя точная англоязычная карта из `data/external-identity/adatours-com-correspondences.json` остается на месте; при конфликте одного EN URL с несколькими RU страницами приоритет имеет срез 22.10.2026. Старые записи других процессов не переписывать автоматически.

Чтобы **удалить временные sameAs VIP**, достаточно поменять в локальном JSON одно поле `"temporaryLegacyVip": false` и опубликовать штатным deploy; пары EN и BrasilTours сохраняются. НЕ менять редиректы или сервер Гарика этим переключением.

Добавление/изменение соответствий после 22.10.2026 — явная точечная редакция локального реестра в GitHub с проверкой уникальности внешних URL, точных RU canonical и действительности страниц. Автоматической синхронизации из Google Sheets нет.

Контроль: `node --test tests/external-page-sameas.test.mjs` (входит в `npm run build`). Выпуск допустим только после штатного успешного Actions build/deploy.
