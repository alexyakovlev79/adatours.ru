# Закрепленные ссылки для сверок Ada Tours ↔ adatours.com

Списки URL для партий №045–076 закреплены в файлах этой папки. Все ID/URL выбраны из исходной очереди на 19.10.2026 (Git blob a109a1fc3a4a4855bcca8c32850d2267158caa90). В каждом файле поле **keys** — точный набор адресов. Номер и логический диапазон служат для отчетов, **не являются индексом изменяемого массива results**.

При начале или возобновлении сверки открывать JSON своего номера и брать ровно его keys. Сначала посмотреть текущие results и verification_batches по точному URL/ID, чтобы переиспользовать уже собранные доказательства; ранее проверенные ссылки не проверять повторно и не заменять соседними ссылками для достижения 50 новых проверок. У каждого адреса один набор фактов, даже если он фигурирует в двух исторических партиях. После проверки обновлять очередь, таблицы соответствий и отчет адресно с учетом параллельных записей.

**Известные расхождения:** партии №049 и №050 пересекаются на 17 URL; отсутствовавшие 17 адресов исходных позиций 2501–2517 закреплены отдельно в [050-backfill.json](050-backfill.json). Партии №058 и №059 тоже пересекаются на 17 URL: использовать сохраненные результаты №059 внутри №058. №045, №047 и №048 оставались без интегрированных результатов на момент заморозки; их файлы задают список, но не означают выполненную проверку. Для №076 осталось 30 адресов.

Для sameAs необходимо доказанное тождество самостоятельного продукта либо одинаковые фильтр и состав каталога. Географическая или тематическая близость недостаточна. Отсутствие подтвержденной пары не доказывает отсутствие английской страницы.

## Проверка покрытия

Исходная очередь: 3780 уникальных ключей. Исторические партии №001–044, этот реестр №045–076, отдельное дополнение №050 и 17 ранее проверенных ключей совместно охватывают все 3780 ключей. Две пары исторических партий имеют по 17 общих URL: №049/050 и №058/059. Они требуют переиспользования доказательств, не двух проверок. Для новых URL, добавленных позднее, создается следующая партия; замороженные наборы менять нельзя.
