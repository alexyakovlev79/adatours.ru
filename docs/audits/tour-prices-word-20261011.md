В описи 169 стабильных записей и 193 файла. Активные страницы есть для 168 записей; единственная программа без соответствующей страницы — P109, PDF «Большой тур по Южной Америке», 33 дня. В PDF нет общей цены. Это отдельная задача создания полного тура, а не исправление цены; с существующим P127 на 14 дней она не объединена.
