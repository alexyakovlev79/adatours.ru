# Подгрузка изображений по экрану устройства

`BaseLayout` обрабатывает HTML основного содержимого через `src/lib/lazy-images.mjs` после извлечения JSON-LD. Настоящие адреса фото находятся в `data-lazy-src` / `data-lazy-srcset`, фоновые CSS-декларации — в `data-lazy-style`. До активации используется прозрачный inline SVG, без сетевого запроса. Обложка с `fetchpriority="high"` загружается сразу для LCP.

`src/scripts/lazy-images.mjs` загружает изображения, хотя бы частично пересекающие текущий экран либо один экран выше/ниже: `rect.bottom > -innerHeight` и `rect.top < 2 * innerHeight`. На старте сверху страницы это первый и второй экраны. Высота измеряется в пикселях текущего viewport, не в процентах `rootMargin` (проценты IntersectionObserver зависят от ширины). При resize порог пересчитывается. При активации img явно получает loading="eager", чтобы нативная ленивая загрузка не откладывала уже разрешенный запрос. Для CSS-фона загрузчик вычисляет background-image текущего устройства и сразу запускает запрос через Image, не дожидаясь отрисовки блока; неиспользуемая desktop/mobile-обложка не загружается. Скрытые и находящиеся вне горизонтального viewport элементы не активируются.

Новые карточки «Показать ещё» обнаруживаются MutationObserver. Закрытые блоки загружаются при открытии. Без IntersectionObserver работают scroll/resize-проверки с requestAnimationFrame. При печати загружаются все фото.

`noscript` восстанавливает обычные изображения и фоны без JavaScript; inline-стиль в head скрывает только прозрачные заменители. Галерея использует имеющиеся `sourceWidth`/`sourceHeight` для сохранения исходных пропорций. Без размеров SVG резервирует 4:3 до получения оригинала; окончательные пропорции определяет существующий CSS. ALT, title, кадрирование и ссылки сохраняются.

Скрытые записи Pagefind содержат адрес изображения в метаданных span, без img и без отдельного запроса. JSON-LD читает оригинальные адреса; HTML-проверка также понимает data-lazy-src. Подготовка CDN переписывает /media/ внутри всех новых атрибутов и noscript штатным способом.

Проверки: `node --test tests/lazy-images.test.mjs`; тест входит в штатный build.
