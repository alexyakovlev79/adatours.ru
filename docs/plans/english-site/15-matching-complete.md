modifiedTime подтвердила даты, сохранённые в результате worker.

самих сохранённых соответствий.

## Контракт следующего этапа
1. Зафиксировать неизменяемый реестр решений 358 задач.
2. Создать stable block maps по текущим RU Tour и выбранным Word,
   с единственным владельцем общей Excursion.
3. Отдельно построить **ценовой план** из всех достоверных Word-2027
   тарифов, сверив с фактическим `main`. Цены 2026 не переносят.
   В план включать единицу цены, SGL/DBL/TPL, сезон/размещение
   и точный XML source locator; отдельные excluded fees не
   превращать в стоимость тура.
4. Уверенное совпадение Word разрешает EN-содержание без
   обязательного ручного review из-за гидов, топонимов или старых
   RU-текстов. Технические неоднозначности цены/структуры
   изолировать и продолжать остальные задачи.
5. Переводческий диспетчер запускается только после пилота
   block map + Word provenance + технической проверки сборки.
   `main`, публичный RU/EN и DNS пока без изменений.

**Это закрытие matching, а не завершение перевода или публикации.**
