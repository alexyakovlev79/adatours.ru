# Ada Tours EN — независимая QA: отменена

**Решение владельца 06.11.2026.** Регулярная и обязательная независимая семантическая проверка массовых EN-переводов полностью отменена. Этот документ не является рабочей инструкцией QA. Старый регламент доступен лишь в Git-истории.

Автоматизация ChatGPT `6aeb7f87aac08191afc7d34f35f32f66` уже выключена (`is_enabled=false`). Не включать повторно, не создавать новую автоматизацию, cron, рецензента или отдельную очередь.

Сохранённый перевод `review` и исторический `ready` одинаково участвуют в ближайшей noindex EN Pages-сборке после технической проверки sourceFingerprint, Git blob, blockId, структуры и связей; обязательный переход `review → ready` отменён. Сохраняются 50 исторически одобренных пакетов и их immutable QA receipts. Массово проставлять `ready` без настоящей проверки запрещено.

Переводчик сам проверяет Word/RU, смысл, цены и коммерческие условия до `submit`. При ошибках технической целостности поле остаётся на RU fallback; остальная EN-часть используется. По отдельной будущей команде владельца возможна адресная редактура конкретного EN-текста с отдельной immutable ревизией; массовая QA при этом не восстанавливается.
