# Ada Tours — старый вход для редакторов ChatGPT / Codex

**Этот путь сохранен для ранее выданных ссылок. Он больше не дублирует регламенты и не является отдельной инструкцией для страниц сотрудников, туров или фотографий.**

**Начни с корневого [AGENTS.md](../AGENTS.md) актуальной ветки репозитория `alexyakovlev79/adatours.ru`.** В нем указано, **где искать действующий процесс для любого изменения**: данные, текст, фото, новый объект, Word, компоненты, SEO/GEO, рои и публикация.

## Доступный способ выполнения выбирается по операции и полномочиям

- **Ограниченная правка поддерживаемых полей существующей сущности:** `docs/workflows/ada-chatgpt-editor.md`. Там описаны допустимые поля, GitHub Issue `[ADA-EDIT]` и проверка публикации.
- **Любой новый/измененный бинарный файл:** `docs/workflows/direct-s3-upload.md`. Если редактор подключен через собственный GitHub-аккаунт, маршрут временного S3-допуска без постоянных ключей — `docs/workflows/editor-s3-token-issues.md`. Это **не тот же Issue**, что редакторская правка; после подтвержденной загрузки нужно адресно изменить файл данных/контента по его собственному workflow.
- **Изменение вне разрешенного узкого редактора:** прочитай профильный workflow из `AGENTS.md`, используй доступный GitHub/Codex/Work маршрут с правами записи и предусмотренным ревью/PR. Подключенный GitHub для чтения, редакторский Issue и среда, где можно загрузить бинарный файл, имеют разные возможности: проверяй каждую, не требуй невозможных полномочий и не выдавай отсутствие одного инструмента за невозможность всей задачи.
- **Публикация:** главный HTML-deploy — `.github/workflows/deploy.yml`. PR, успешный Issue, commit, загруженный файл и реальный успешный Pages deploy — разные состояния. Отчитывайся по фактическим подтверждениям.

Никакого WordPress и `/wp-admin/` у сайта нет; действующий сайт — Astro + GitHub Pages, медиахранилище — Yandex Object Storage. Не создавать дублирующую архитектуру, постоянные S3-ключи или новое руководство для каждого объекта. Исторический текст этого файла доступен в истории GitHub.
