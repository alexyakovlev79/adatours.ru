# P05 — общая логика видеообложек

Запрос Алексея22.10.2026: hover-only desktop, центр/очередь на touch, стоп при выходе любого края, уменьшение мобильных карточек стран на10–15%, переиспользование чужих hero по форме области на всём сайте. Отдельно уточнено: названия стран на примерах не должны становиться условиями кода.

## Реализация

Контроллер `src/scripts/video-covers.mjs` и чистая политика `src/lib/cover-playback-policy.mjs` едины для всех обложек. Формат заимствованного видео выбирается по измеренным width/height области на любом устройстве. Собственный первый hero сохраняет device-вариант. На desktop требуется курсор внутри области и полная видимость; уход возвращает первый кадр и время0. На touch первый hero работает при полной видимости, остальные после пересечения центров. Ряд определяется геометрией, порядок — фактический left; ended передаёт ход следующему слева направо. После конца ряда цикл повторяется. Полная видимость важнее очереди, новый центрированный ряд получает ход. Скрытая вкладка останавливает видео.

Кадры и фото-ветка ждут прежнего окна `isWithinImageWindow`; MP4 не получает src до условия play. Отдельное редакционное фото в видео-режиме остаётся инертным. Кадр берётся из действующего реестра по точному видеофайлу. Сам ролик не перекодируется и новые медиа не создаются.

Общий каталог строится из активных RU hero.src + heroVideo + canonical owner. Собственная страница исключена из заимствования; конфликт разных роликов у одного фото явный. Подключены Hero, обе разновидности DestinationBand, InterestCard, StoryPair, карточки мест/экскурсий страны, галереи, главные впечатления, изображения дней тура/встроенных экскурсий и остальные фотокарточки главной. Общая schema и шаблоны Country/Destination/Tour/Excursion/Theme/Case поддерживают независимые src/mobileSrc. На текущих данных реальные источники — главная и Бразилия. Для остальных сущностей ролики не выдумывались.

Страны главной до760px: высота clamp(360px,105vw,460px) → clamp(315px,91.875vw,402.5px), −12,5%. На обычных мобильных ширинах это горизонтальная область; общий выбор позволяет существующий горизонтальный ролик Бразилии, без отдельного условия по стране.

## Проверки до публикации

-18 Node tests:10 новых правил (формат, устройства, края,2–4 видео, пересечение между кадрами, смена ряда, источник и кадр),4 прежних device-вариантов,4 прежнего окна загрузки. Новая политика и device tests включены в штатный build.
-14 сценариев фактического клиентского runtime в jsdom: нет запросных URL до окна; только кадр до hover; hover/out/rewind; выход края; touch последовательность; отсутствие вертикального варианта → фото; resize → горизонтальный ролик; собственный hero планшета; скрытие вкладки; cleanup. Это DOM-обвязка, не физический телефон.
-Изолированная Astro SSR-сборка фактических компонентов с настоящей content collection:7 интеграций. Подтверждены ориентационный режим, placement, инертные фото, отсутствие активного MP4 и вложенных button в a, обычное фото без видео. Полная локальная сборка достигла content gate и остановилась из-за2981 legacy-медиа, сознательно не скачанных в sparse checkout; проверка реальных медиа и полный build выполняются единственным штатным Actions deploy. Проверки не отключались, фиктивные медиа не создавались.
-Компиляция изменённых Astro и клиентских модулей прошла. Новые бинарные медиа отсутствуют. Файлы временной SSR-проверки и npm lock не включаются в публикацию.
