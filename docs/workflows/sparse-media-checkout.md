# Ada Tours: checkout без исторической медиатеки

Дата: 30.10.2026. Мигрированные изображения хранятся в Yandex Object Storage. В существующей версии Git их бинарные копии остаются как история, но на CI/Pages сборках они не нужны.

Тестовый режим использует Git sparse-checkout с исключением только public/media/. Все компоненты, скрипты, MD/JSON, public/brand, phone-flags, CSS и служебные файлы остаются. scripts/prepare-pages-media.mjs проверяет, что ссылки в выходном HTML полностью переведены на https://img.adatours.ru/media/, и допускает только два состояния: старый полный media-каталог (который удаляется из dist) или отсутствие public/media и dist/media. Частичная копия отклоняется.

Главная цель — не переносить 1.44 ГБ старых бинарников в каждый runner. Ничего из Git-истории не удаляется, бинарные объекты в S3 остаются. После подтвержденного PR CI допустимо аналогично настроить build checkout в .github/workflows/deploy.yml. При любой ошибке сборки или нехватке нужного локального файла checkout возвращается к полному до отдельного устранения причины.
