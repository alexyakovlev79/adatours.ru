1. Зафиксировать архивный фильтр в переводческой очереди (не удаляя 358 исторических результатов). Перед выдачей задания сверять актуальные `status`, `sourceFingerprint` и наличие Tour MD.
2. По 2027 Word проверить каждую предлагающуюся сумму вместе с `priceBasis`, валютой, группой/человеком, DBL/SGL/TPL, сезоном, доплатами и точным XML `sourceLocator`. Начать с адресного пилота 3–5 туров. Не превращать билеты и дополнительные экскурсии в `priceFrom`.
3. Применять только подтвержденные общие тарифы к RU/EN через канонические поля и производные SEO/Schema; архивные Tour не обновлять. Подготовка ценового плана не меняет `main` и не подтверждает публикацию цены.
4. В параллельном техническом треке завершить Word → stable block alignment, отдельный CAS-диспетчер переводчиков и locale adapter Astro. Только после пилота и checks открывать массовый EN-перевод. Не переводить весь каталог из-за результата одной диагностики.
