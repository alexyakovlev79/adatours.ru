# Ada Tours — разделение «Природа и животные» на 2 интереса

Версия: 1.0 · 20.10.2026 · задача по прямому поручению пользователя.
Рабочая ветка: `feature/split-nature-wildlife-20261020`. Production: `main`.
Baseline main: `53eddd1a58c69c7b21ae5ea412e4deb8068953ff`.

## Решение об идентичности

Всего 15 интересов вместо 14.
- `theme_wildlife`, URL `/interests/wildlife/` — **Животные и сафари**, сохранение ID, URL, входящих ссылок и истории SEO.
- `theme_nature`, URL `/interests/nature/` — **Природа**, новый ID/страница/тексты/hero.

Никакого массового переименования существующих contentPath, медиа, старых URL или source ID.
Старый `theme_wildlife` — самостоятельная тема животных, а не alias природы.

## Зафиксированный первоначальный объем

- 518 из 1018 Destination.
Итого 1025 *каталожных* записей с прежней меткой; не считать автоматически все активными или опубликованными.
Production MD в `src/content/`: около 392 Tour, 416 Excursion, 999 Destination. Проверять наличие точного MD по `entry.contentPath` для каждой выбранной записи.

## Семантическая классификация

**Природа** — самостоятельный повод поездки: водопады, горы, вулканы, ледники, пустыни, фьорды, каньоны, леса, джунгли, озера, заповедные ландшафты; ландшафтные маршруты, пешие прогулки ради видов, знакомство с природными территориями. Лишь транзит мимо природного объекта не основание.

**Животные и сафари** — реально включенные выезды/наблюдения за дикими животными, птицами, морской фауной; фото/джип/лодочные сафари, бердвотчинг, поиск животных с натуралистом. Упоминание возможной фауны парка, случайная птица на маршруте, зоопарк, обычное посещение леса и необязательная экскурсия не основание. «Сафари» как текстовый штамп без наблюдения не основание.

**Обе темы** — у самостоятельного продукта существенно представлены и природные территории/ландшафты, и отдельные выезды/наблюдения за животными. Решение принимать по содержанию подтвержденной программы, а не названиям, alt, поисковым алиасам или характеру родительского тура.

**Tour**: сохранить 1–2 `primaryThemes` суммарно (по ведущим причинам покупки), прочие существенные темы в `themes`; массивы без пересечений/повторов. Если старая тема была primary, выбрать primary у наиболее сильной из двух; при двух иных уже primary менее значимую перенести в secondary. Не менять другие темы без конкретного обоснования.
**Destination/Excursion**: самостоятельные `themes` только по собственному описанию, без наследования от Tour; пустая тема допустима. Случаи ниже уверенности 70% оставлять `REVIEW`, не подписывать наугад.
**Archive**: не размечать архивные Tour/Excursion заново и не менять их жизненный статус; исторические поля сохранять. Для активного каталога исключаются независимо от старых тегов.

## Антизависание и последовательность

Работать **только в отдельной ветке**, пока migration-coverage не достиг 100% и не прошел полный CI; `main` должен оставаться консистентным со старыми 14 интересами до одномоментного cutover.

- Этап A: этот handoff и замороженный baseline (DONE).
- Этап B: подготовка/тесты 15-темной структуры, нового природного hero и текстов. Коммит.
- Этап C: миграция 1025 записей, только активных MD, порциями по 10–20 объектов; отдельный коммит и обновленный decision-ledger после каждой партии. Новые записи, появившиеся после baseline, до cutover проверять по `main`.
- Этап D: однократная генерация SEO/GEO/фильтрованных каталогов, адресная редактура опубликованных статей, документы, CI.
- Этап E: свежий rebase/точечный перенос на main без уничтожения параллельных правок; deploy по SHA; после успешного deploy синхронизация внешних реестров; итоговые счетчики.

**Ledger**: `data/migrations/interest-split-20261020/decisions.json` — записи ключом `type:id`, со статусом `done|review|skipped_archived`, исходными метками, итоговыми, `contentPath`, `evidence`, `sourceBlobSha`, `commit`. Внедрить или поддерживать этот файл вместе с первой пачкой. Сохранить решение и точные MD/source-entry в том же коммите, не считать решение `done` без подтвержденного коммита.

После ошибки: прочитать только текущую ветку, ledger и последний подтвержденный коммит; исправить недостающий шаг конкретной пачки. Не повторять закрытые объекты, не стирать готовые решения, не переписывать `main` force. Если `main` продвинулся, применить изменения только к нужным файлам на свежей базе; конфликт маркировать `review` с SHA обеих версий.

Условия финальной публикации: 15 тем/15 индивидуальных текстов/15 готовых hero; все активные старые `theme_wildlife` идентифицированы как природа/животные/оба; нет неизвестных theme ID и нарушений primaryThemes; MD=exact entry=compact catalog по каждому измененному ID; все активные тематические страницы строятся, SEO articles осмысленны, CI success, нет сломанных ссылок и случайного переноса архива. **Не сливать частично размеченную ветку в production.**
