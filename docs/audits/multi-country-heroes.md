# Обложки сочетаний multi-country

Задание Алексея от 15.10.2026: создавать самостоятельные hero через Imagegen партиями по 10. Кадр должен объединять хотя бы две страны выбранной комбинации: общая территория, ландшафт или сюжет путешествия. Обложки туров не заменять.

Редактируемый реестр: `src/data/media/multi-country-heroes.json`. Ключ — канонические country slugs, отсортированные и соединенные `_`, как у `buildMultiCountryCombinations`. Страница и ее пагинация используют `covers[key].src`; пока записи нет, сохраняется прежняя обложка тура.

Первая партия: 10 отдельных Imagegen-генераций, сохраненных в WebP без обрезки; загружены непосредственно в S3, SHA-256 проверены обратным скачиванием. Каждая имеет запись в `photo-enhancements.json` и `direct-s3-uploads.json`. Бинарные файлы в Git не добавлялись. Сюжеты и страны связи сохранены в `covers`.

Порядок продолжения: канонический ключ по возрастанию, пропуская уже заполненные `covers`. На момент первой партии всего 199 сочетаний, заполнено 10, осталось 189. Следующий ключ: `argentina_brazil`.

Перед следующей партией пересчитать существующие сочетания из активных RU-туров по основным странам маршрута. Не использовать дополнительное посещение как основную страну. Готовые cover и receipts повторно не генерировать. Новые файлы — только по `docs/workflows/direct-s3-upload.md`, с новым версионированным именем.
