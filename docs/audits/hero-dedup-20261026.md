# Точные дубли hero — публикация подготовленного пакета

План от 26 октября 2026: 1799 активных обложек туров, мест и экскурсий; 93 группы точных дублей. Подготовлено 127 уникальных GPT Image изображений: 49 для туров, 22 для мест и 56 для экскурсий. Двенадцать партий по 10 и последняя из 7.

Публикация явно разрешена Алексеем 27.10.2026 командой «публикуй». Изображения получены в предыдущем проходе; их SHA-256 сверены после восстановления пакета. Новый этап только загружает и связывает эти готовые файлы.

Полный список файлов и владельцев: `data/audits/hero-dedup-20261026.json`. Подтвержденные S3 uploads и привязки: `data/audits/hero-dedup-20261026-results.json`, общий `src/data/media/direct-s3-uploads.json`.

Для каждого нового source подготовлены мобильные версии 480×640 и 648×864. Оригиналы и cover 320×700, 412×556, 479×400 визуально проверены при подготовке; значения фокуса и geometry сохраняются в новом mapping точной страницы и source/hash.

Commit содержит MD, source-index, происхождение Imagegen, подписи, мобильный реестр и verified receipts. Новые бинарные медиа в Git не добавляются. Завершение публикации подтверждается штатным `ada/pages-deploy` для этого commit, а не самим наличием данных в репозитории. После успешного deploy адресно обновляется лист «Фото».

Перед публикацией у пяти новых мест обнаружены еще два дубля: Сан-Исидро и Пасео-Югославо. Для них 27.10.2026 сгенерированы задания 126–127; первоначальные 125 заданий сохранены. Всего 381 verified WebP.
