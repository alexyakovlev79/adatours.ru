## Реализованная редакционная рамка

1. **MICE:** выполняемые виды работ, 2 действительно выполненных кейса, связь с подробными предлагаемыми программами, параметры расчета, FAQ без обещаний незафиксированной коммерческой политики.
2. **Делегации:** фактический опыт 8 человек, подготовка профессиональных визитов только после согласия принимающих организаций; аграрная программа как предложение, а не кейс; требования к брифу.
3. **B2B-программы:** свежие три Word-программы в начале списка, маркировка в тексте как программ для адаптации, разбор форматов, FAQ о включенных услугах и подтверждениях.
4. **DMC/B2B:** связь между обслуживанием, кейсами и программами; вместо неподтвержденного процента вознаграждения — перечень условий, которые нужно согласовать.
5. **Турагентствам:** задачи обеих сторон для согласования, перечень первого брифа, вопросы о контакте с туристом и формате документов без обещания white-label.
6. **Условия работы:** нейтральные условия формирования предложения, подтверждения мест, тарифов, отмен и помощи; **ни один непроверенный вариант нетто/процентной комиссии не представлен как действующая политика**.

Существующие ID, URL, CTA и единственная общая форма в `BaseLayout` сохраняются. Дополнительный общий компонент `CommercialDetails.astro` использует компактные текстовые строки без лишних полноэкранных фотоблоков.
