# Ada Tours: ускоренная сборка без пропуска проверки опасных изменений

Дата: 30.10.2026. Полная команда npm run build остается стандартом для CI, PR и любых неизвестных типов изменений.
В Pages workflow только при известном точном Git push SHA классификатор сравнивает старую и новую версии каждого затронутого файла. Лимит 24 файла.

## Допускаются в облегченный режим

- Редакционные тексты и изображения существующих сотрудников в src/data/organization/team.json, с сохраненными id, составом и схемой полей.
- Вступления и редакционные заголовки тем в src/data/interest-copy.json, с неизменными грамматическими формами и ключами.
- Исправления обычной прозы в существующих Country/Destination/Tour/Excursion/Theme/Person MD, без изменения frontmatter, заголовков, ссылок, разметки или структуры строк.
- Добавление новых S3 receipts и записей GPT Image, без изменения старых квитанций и записей.
- Документация, в том числе в одной партии с разрешенными изменениями.

Новые и удаленные страницы, новые участники команды, цены, даты, маршруты, SEO-реестры, код, шаблоны, CSS, ссылки, конфигурация и все неизвестное запускают полную сборку. Если нет базового SHA или возникла ошибка сравнения, используется полная сборка.

## Что никогда не отключается

При любом режиме заново строятся все HTML через Astro, генерируются необходимые соцпревью и Pagefind, перенаправляются ссылки на S3 и выполняется дедупликация HTML. Сам Pages deploy блокируется, если независимо идущая проверка S3 завершилась ошибкой. Фотографии публикуются только по подтвержденным объектам.

Ускорение касается только дорогих глобальных проверок при заведомо безопасных правках. Изменение критериев требует отдельного теста с негативными примерами.
